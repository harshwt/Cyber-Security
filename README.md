# OSINT (Open-Source Intelligence)

This folder contains resources and tools related to Open-Source Intelligence (OSINT).

## What is OSINT?
Open-Source Intelligence (OSINT) is the collection, analysis, and dissemination of information that is publicly available and legally accessible. It is widely used in cybersecurity, threat intelligence, penetration testing, and investigative journalism to gather insights about targets without engaging in active probing or scanning.
